# Mathematics and quantum foundations

This topic supplies the concepts that state notation, measurement, gates, and calibration previously assumed. It starts with complex numbers, vectors, matrices, and probability, then uses those tools to describe quantum states, operators, measurements, unitary gates, and number states.
