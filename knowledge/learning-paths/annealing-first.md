# Annealing from model to evidence

This path separates three questions: what the annealer samples, how a real problem reaches it, and what evidence supports a comparative claim.

Checkpoints:

1. Explain the difference between Ising spins and binary QUBO variables.
2. Describe why hardware connectivity creates minor-embedding chains.
3. Enumerate the worked two-variable QUBO by hand.
4. Name every classical step around the QPU call.
5. Distinguish quantum processing time, time to solution, and end-to-end time.
6. State an advantage claim as task, method, metric, accuracy, and comparator.
