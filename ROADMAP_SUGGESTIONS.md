# Roadmap Suggestions

These are candidate batches after the current roadmap. Keep each batch optional and preserve the free offline core.

- [ ] **Learning accessibility assessment:** turn Feedback 2 into tested ADHD-friendly focus modes, shorter study sessions, collaborative non-punitive feedback, and resumable checkpoints.
- [ ] **Circuit composer vertical slice:** begin with one to three qubits, common unitary gates, inverse controls, amplitude display, save/load, and deterministic local simulation.
- [ ] **Ariadion adapter:** verify a tagged public API and use it only for capabilities it implements well; keep a tested built-in fallback and explicit version contract.
- [ ] **State inspection labs:** add Bloch, state-vector, and density-matrix views with clear pure/mixed-state and noise-model boundaries.
- [x] **Mobile distribution:** ship the progressive web app first; evaluate native wrappers only if offline installation, file transfer, and platform testing later justify them.
- [ ] **Project identity and release:** choose a durable name, settle Python-versus-web packaging boundaries, test TestPyPI/PyPI publication, and prepare tutorials and community channels.
